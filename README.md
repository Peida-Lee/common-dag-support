# Common-DAG Support from Targeted Covariance Changes under Confounding

Peida Li, School of Basic Medical Sciences, Peking University.

This repository contains the signed preprint and the final reproducibility package.

## Contents

- `paper/common_dag_support.pdf` is the signed 30-page preprint.
- `paper/common_dag_support.md` provides the same scientific text.
- `paper/arxiv_source.zip` contains the minimal TeX source and referenced figure.
- `reproducibility/` contains the paper's final experimental specifications, numeric inputs, scientific code and outputs.

## Reproducing the paper

Follow `reproducibility/README.md` to install the pinned Python and Julia environments, create a fresh execution directory and run the declared experiments. The package includes 2048 Gaussian conditions, 96 connected population conditions, four measured application interfaces, and the exact root-target compatibility checks.

The measured estimators were developed on the public acquisitions evaluated in the paper. The fixed final replay and its inputs are recorded in the supplied freeze and execution manifests. The paper distinguishes working-reference scores, physical-label uncertainty, and the objects tested by each application interface.
